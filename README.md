# LUPIN — Những đêm không cửa (bản thử web)

Bản chơi thử phần mở đầu ở bến cảng Dieppe, năm 1905. Bạn vào vai thám tử Herlock Sholmès.

**Chơi:** mở trang GitHub Pages của repo này (nên dùng Chrome hoặc Edge trên máy tính).

- Điều khiển: W A S D để đi · giữ Shift để chạy · bấm Shift liên tục để chạy nước rút · Space để nhảy · E để nói chuyện, ngồi, dựa tường · chuột để xoay máy quay · M mở bản đồ · Tab mở sổ tay · Esc để tạm dừng.
- Bấm vào khung game một lần để khoá chuột. Bấm Esc để nhả chuột.

Làm bằng Godot 4.7. Nhân vật Arsène Lupin và Herlock Sholmès lấy từ truyện của Maurice Leblanc (đã thuộc phạm vi công cộng).
